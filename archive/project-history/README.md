# 项目历史归档

本目录保存不再作为当前控制面真源、但需要可追溯的原文。归档不进入 Agent 默认读取，也不应被当成当前发布或产品合同；需要历史证据时，先按下列分类或定向 `rg` 定位。

| 目录 | 内容 | 读取规则 |
| --- | --- | --- |
| `control/` | 已归档的 PLAN 与上下文读取规则快照 | 仅用于解释某一历史阶段 |
| `dev-reports/` | v1 实施报告、RC1 报告和 taxonomy real-run 记录 | 不作为当前验收或发布流程 |
| `design/` | 已被产品范围收口的旧设计 | 仅作设计背景 |
| `runbooks/` | 已替换的操作手册原文 | 不执行其中命令；先读现行手册 |
| `init-pro/`、`reference/`、`sdd-reports/`、`superpowers/` | 既有规划、审计和参考资料 | 按任务定向读取 |

历史原文以 `git mv` 保留；若需要核对某次迁移，可使用 Git 历史和 SHA-256，而不是复制回活动控制面。
