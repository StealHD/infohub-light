# Inteliscope Feed Quiet Studio 设计规格

**日期：** 2026-07-18
**状态：** 用户已确认视觉方向、交互原型与书面规格

**范围：** 仅 `/feed`；不扩散到收藏、历史、订阅、设置、登录或 Agent 内容设计

## 1. 目标与设计依据

在当前 HeroUI 暗色工作台基础上做克制的视觉微调，使信息流更安静、更易扫读，并让悬停、展开和 Agent 面板切换具有明确但不过度的反馈。

Apple 设计仅作为设计原则参考，不做组件或像素复刻。本方案采用以下原则：

- 内容优先：卡片使用稳定的标准表面，不把玻璃效果铺在内容层。
- 控件与内容分层：轻微半透明和模糊只用于顶部控制区及瞬时控件。
- 简化：删除不再服务阅读任务的进度刻度，每个可见元素都必须有明确用途。
- 对齐与留白：标题、元信息、正文和操作使用一致的左边界，形成稳定的扫读路径。
- 动效传达状态：动效只说明悬停、按压、展开和面板切换，不作为装饰。

参考：

- [Apple Human Interface Guidelines — Materials](https://developer.apple.com/design/human-interface-guidelines/materials)
- [Apple Human Interface Guidelines — Layout](https://developer.apple.com/design/human-interface-guidelines/layout)
- [Apple Human Interface Guidelines — Motion](https://developer.apple.com/design/human-interface-guidelines/motion)
- [Apple Human Interface Guidelines — Typography](https://developer.apple.com/design/human-interface-guidelines/typography)

## 2. 已确认方向

用户从三个候选方向中选择 A「Quiet Studio」，并确认交互状态原型。

已确认的关键判断：

- 删除 `/feed` 左侧所有进度刻度及其预留空白。
- 顶栏右侧 Agent 开关换成双栏面板图标：圆角矩形外框，右侧窄栏，以开合状态表达面板可见性。
- 使用 macOS 系统字体栈；中文回退为苹方和本地 Noto Sans SC。
- 内容卡片继续存在，但弱化阴影和装饰，依靠轻微明度差、细边界和留白建立层级。
- 卡片点击后在原位置展开正文；不打开新的详情层，也不占用 Agent 面板。
- Agent 面板仍用于上下文交接，与阅读详情保持职责分离。

## 3. 页面结构

### 3.1 顶栏

- 高度保持 52–54px，避免牵动全局 Shell。
- 左侧只显示“信息流”。
- 右侧只显示 Agent 面板开关。
- 不恢复搜索框或“更新信息流”按钮。
- 顶栏使用接近不透明的深色表面；支持时使用轻度背景模糊，失败时必须保持同等文字对比度。
- 双栏开关点击区域为 34×32px，图形约 18px；悬停出现中性浅底，开启态使用低饱和紫色浅底。

### 3.2 紧凑工具行

- 文案收敛为“`N 条内容 · 最新在下`”。
- 不显示没有操作价值的“全部”状态 Chip。
- 筛选入口保留在右侧，使用紧凑按钮；当前存在筛选时显示数量或状态点。
- 工具行滚动到内容顶部时可以保持可见，但不使用厚重背景或明显阴影。

### 3.3 信息流容器

- 删除进度轨后，Feed 不再保留 64px 左侧轨道空间。
- 桌面卡片内容列最大宽度约 820px，在可用区域居中。
- 卡片之间使用 12px 垂直间距，列表顶部约 14px、底部保留新内容提示和安全空间。
- 排序、首次定位到底部、新内容提示和虚拟列表语义保持不变。

## 4. 卡片视觉

### 4.1 默认状态

- 背景目标接近石墨色标准表面 `#17171A`，实现时必须映射为设计系统语义 token。
- 边界目标接近 1px 低对比色 `#29292E`，实现时必须映射为设计系统语义 token。
- 圆角：18px。
- 不使用发光、整圈紫色描边或持续重阴影。
- 来源行、标题、摘要和操作区使用同一左边界。

### 4.2 信息层级

- 来源头像约 25px。
- 来源、作者和时间使用 11px 次级文字。
- 标题使用 16px、半粗字重和紧凑行高。
- 摘要使用 13px 次级文字，默认最多两行。
- 频道和主题使用 10px 紧凑标签；主题不应争夺标题注意力。

### 4.3 操作区

- 保留打开原文、收藏、加入 Agent 上下文和更多菜单。
- 桌面默认操作图标约 56% 不透明度；卡片悬停或键盘聚焦时提升到 100%。
- 触摸设备不依赖悬停，操作始终可见。
- 桌面操作点击区域约 29×29px；触摸布局扩展到至少 44×44px，并继续遵守现有可访问性门禁。

## 5. 交互与动效

### 5.1 卡片悬停与按压

- 悬停时卡片上移 1px，边界和表面轻微变亮。
- 不使用明显缩放，避免长列表滚动时产生晃动。
- 操作按钮按压允许约 0.91–0.95 的瞬时缩放反馈。
- 悬停/按压变化控制在 140–180ms。

### 5.2 原位展开

- 点击标题与摘要区域切换展开；点击底部操作不得触发展开。
- 展开内容位于摘要下方，用细分隔线区分。
- 高度与透明度在约 220ms 内变化；使用平稳的减速曲线。
- 再次点击同一区域收起。
- 继续复用现有滚动锚点保护，不抢走用户滚动位置。
- 展开行为不自动标记已读，深链和 URL 语义保持不变。

### 5.3 Agent 上下文

- “加入 Agent”点击后图标切换为确认状态，并使用低饱和紫色底表达已加入。
- 继续遵守最多 8 条、稳定顺序和账号隔离。
- 不伪造 Agent 在线状态或站内聊天能力。

### 5.4 Agent 面板开关

- 关闭态：仅显示双栏线性图标。
- 悬停态：出现低对比中性底色。
- 按压态：约 0.94 的瞬时缩放。
- 开启态：图标右栏出现轻微填充，按钮使用低饱和紫色浅底。
- ≥1200px：面板以约 340–360px 宽度参与三栏布局。
- 768–1199px：从右侧覆盖进入。
- ≤767px：继续使用 Bottom Sheet。
- 开关面板不得改变 Feed 当前滚动位置；关闭后焦点归还开关按钮。

### 5.5 Reduced Motion

- `prefers-reduced-motion: reduce` 下取消位移、缩放和高度过渡。
- 状态变化必须仍能通过颜色、图标和 ARIA 属性理解。

## 6. 响应式与兼容边界

- 桌面、平板和移动端都不再显示 Feed 进度刻度。
- 移动底部导航保持现状，本次不重新设计。
- 收藏与历史继续使用当前视觉和功能，不继承 Quiet Studio 卡片调整。
- 不修改后端 API、数据库、权限、Query Key、Worker、Remote MCP 或历史数据。
- 不引入新组件框架；继续使用 HeroUI、Tailwind CSS、现有设计系统出口和 Lucide/内部图标。

## 7. 无障碍与错误行为

- Agent 开关保留 `aria-label`、`aria-expanded` 和 `aria-controls`。
- 卡片展开控制保留 `aria-expanded`，操作按钮具有独立可访问名称。
- 焦点环使用现有全局 focus token，不被圆角或 overflow 裁切。
- 颜色不是唯一状态表达：Agent 开启和上下文加入同时通过图标/ARIA 表达。
- 现有加载、空态、错误和重试行为保持不变；视觉调整不得吞掉状态提示。

## 8. 验收标准

- `/feed` 不存在搜索框、“更新信息流”、进度刻度或其预留空白。
- 右上角显示已确认的双栏 Agent 图标，开关状态可视觉和无障碍识别。
- 桌面默认能舒适显示约 3–5 张真实高度卡片，长中文、日文和英文标题均不溢出。
- 卡片原位展开和 Agent 面板开关不改变 Feed 滚动位置。
- 收藏、历史和其他页面无视觉回归。
- 键盘、触摸、Reduced Motion 和三个目标视口通过现有 Playwright/Axe 门禁。
- 200 条数据仍由虚拟列表控制 DOM 数量，视觉调整不降低滚动稳定性。

## 9. 非目标

- 不做 Apple 网站或 macOS 应用的 1:1 复刻。
- 不实现 Liquid Glass 内容卡片。
- 不增加新的 Feed 功能、筛选维度或 Agent 后端。
- 不在本轮统一重构全站设计系统。
