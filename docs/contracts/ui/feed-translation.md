# Feed 卡片正文翻译

Feed、收藏、历史的文字卡片在右下角提供 Languages 线框图标，复用既有卡片操作按钮角色、尺寸和 Tooltip；专题速览的紧凑行也允许此翻译入口。点击展开原文并在其下方显示独立的“中文翻译”区域，原文、图片、标题和其他操作保留。按钮再次点击收起/展开译文；仅显式点击才请求翻译，模型使用“设置 → AI”的配置，目标固定简体中文。

等待/运行状态在译文区域显示，按钮轨道固定并防重复提交；失败保留原文且提供本地重试，管理员遇到模型未配置可前往 AI 设置。仅有摘录时标注“仅翻译已抓取摘录”，截断正文标注“仅翻译已抓取正文片段”；无可翻译正文或 Viewer 时禁用并给出可访问说明。翻译查询、展示状态与用户绑定，遵循异步连续性、虚拟列表锚点、触屏和 Reduced Motion 规则。
