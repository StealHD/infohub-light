# D176–D200 决策记录

### D176 OpenClaw 专属架构先行，通用 Agent Core 延后

- 决策日期：2026-08-22
- 当前状态：已实施；只重构既有 OpenClaw、Remote MCP 与本地安装入口，不改变用户可见行为或运行合同。
- 决策内容：先以显式 `OpenClawChatController`、状态/Event/Port 合同、单一 Gateway Event Router、纯 Domain Projection、根 Reducer、Workbench Adapter、Remote MCP 三类 registrar 和 focused read/diagnostic/setup 模块稳定现有 OpenClaw 边界。历史 import 路径保留为显式兼容 façade，17 个 Remote MCP 工具、OpenClaw Protocol、scope、权限、数据库与部署保持不变。通用 Agent Core、capability registry、新 scope、新工具、用户配置体检、采集缺口检测、补采计划与核验、其他 Agent Adapter 延后到本重构合并并稳定后的独立分支和计划。
- 原因：当前只有一个已投入使用的 Browser Agent 适配器；在尚未稳定事件、状态、存储、Workbench 和 MCP 接缝前抽取通用 Core，会把 OpenClaw 特有协议误固化为全局抽象，并把纯结构重构扩大成 capability、授权和数据面的同时变更。先建立可执行的单向依赖与兼容 façade，后续才能用第二个真实 Adapter 需求验证通用接口。
- 兼容/边界：本决策不授权新增 Agent capability、工具、scope、数据库、迁移、ActorOps、Worker、Job、采集、AI、通知或发布操作。任何后续通用化都必须重新评估公共合同、权限、威胁边界和迁移策略，不得在 OpenClaw façade 内暗中扩展。
