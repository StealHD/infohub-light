# Decision Records D201–D225

<a id="d201"></a>
### D201 异步操作按钮以双层占位保持稳定几何

- 决策日期：2026-09-02
- 当前状态：本地实现、静态合同检查与定向组件测试完成；未部署。
- 决策内容：所有会进入保存、提交、测试、应用、连接、删除等非终态的文字按钮统一使用设计系统 `StableAsyncButton`。静态文案与中间态文案必须同时占据同一布局轨道，只切换可见性与可访问名称，外层按钮节点、宽高和周边布局保持不变；中间态期间按钮禁用并暴露 busy 状态。刷新与重试请求使用专用 `RefreshButton`：按下立即旋转固定位置的 `RefreshCw`，快请求仍保留至少 400 ms 可感知反馈，长请求持续到完成，Reduced Motion 下保留 busy 与禁用语义而取消旋转。业务组件不得直接给普通 `Button` 绑定 `refetch()`，也不得通过替换子节点改变几何。只有真实语义角色切换、且固定尺寸角色或对应路由合同明确允许时可以例外，并需浏览器验收覆盖。
- 门禁与兼容：UI 合同检查拒绝普通 `Button` 直接按异步状态切换文案；现有异步文字按钮迁移到同一组件。通知设置保存不再以缓存内容作为 React `key` 重新挂载整张表单，因此保存前后保持同一按钮与表单实例。接口、权限、保存 payload 与业务反馈不变。
- 原因：按钮文字长度变化和保存成功后的整块重挂载会造成操作区横向跳动、焦点丢失与“页面被替换”的观感。把两个状态预先纳入同一几何测量，并由可执行门禁约束后续代码，才能稳定所有类似操作而不依赖逐页面手工指定宽度。

### D202 外部 UI 教材蒸馏为单一交互宪章

- 决策日期：2026-09-02
- 当前状态：项目级交互宪章、Skill 入口、验收清单和影响映射已接入；D201 的稳定异步/刷新按钮及现存页面迁移已先行完成，未部署。
- 权威边界：项目继续以 `AGENTS.md → docs/contracts/ui → component-parameters → frontend/src/design-system → check-ui-contract` 为法律链，不安装、不复制、不自动跟随外部 Skill。新增 `interaction-constitution.md` 是跨页面交互行为的唯一真源；`.agents/skills/inteliscope-ui/SKILL.md` 只负责自动发现、读取顺序、异议上报和验证入口。外部教材固定为 UI UX Pro Max commit `40d8b6facf46677f86e8c0e5d4c6f77c137c9888`，上游更新只有经过显式复审和新决策才可能影响项目法律。
- 吸收内容：将稳定布局、异步单飞、局部且可恢复的错误/空状态、长 token 与紧凑集合重排、稳定业务 key、DOM/焦点/滚动连续性、键盘可操作性、可见焦点、语义 live status 和 `prefers-reduced-motion` 改写为 React/HeroUI/现有语义组件可验收的规则。特别强化按钮外框稳定、loading copy 不挤动布局、刷新/重试保留原图标与文案并原位旋转、pending 禁止重复触发、保存/刷新不得重挂 form/card，以及业务正确性不得只依赖动画结束事件。
- 舍弃内容：不引入风格、配色、字体组合、落地页和图表目录，不引入 GSAP/shimmer 预设、shadcn/native/mobile 专属约定、外部 breakpoints/max-width、统一桌面 44/48 px 控件或全局 16 px 字号。项目已有 Quiet Studio、11 个排版角色、三视口、PageFrame、32/40 px 桌面控件与粗指针 44 px 目标继续优先。
- 现法疑点：现有 `type-control` 13 px 也用于部分移动输入控件，可能触发 iOS Safari 聚焦自动缩放。用户已裁决本次保持现法，因此这只是非规范性后续审计项，不进入宪章、不改变令牌，也不以外部 16 px 规则覆盖项目法律。
- 后续维护：跨路由行为只追加到 Constitution，数值只进 component matrix，页面例外只进 route contract，验收只进 acceptance，机械规则只进现有 checker/test pair；只有发现、读取流程或外部参考入口变化时才修改 Skill。无法安全静态判断的几何、DOM 身份、焦点和滚动连续性继续由组件/浏览器验收约束，不用宽泛正则制造假合规。
