### D201 异步操作按钮以双层占位保持稳定几何

- 决策日期：2026-09-02
- 当前状态：本地实现、静态合同检查与定向组件测试完成；未部署。
- 决策内容：所有会进入保存、提交、测试、应用、连接、删除等非终态的文字按钮统一使用设计系统 `StableAsyncButton`。静态文案与中间态文案必须同时占据同一布局轨道，只切换可见性与可访问名称，外层按钮节点、宽高和周边布局保持不变；中间态期间按钮禁用并暴露 busy 状态。刷新与重试请求使用专用 `RefreshButton`：按下立即旋转固定位置的 `RefreshCw`，快请求仍保留至少 400 ms 可感知反馈，长请求持续到完成，Reduced Motion 下保留 busy 与禁用语义而取消旋转。业务组件不得直接给普通 `Button` 绑定 `refetch()`，也不得通过替换子节点改变几何。只有真实语义角色切换、且固定尺寸角色或对应路由合同明确允许时可以例外，并需浏览器验收覆盖。
- 门禁与兼容：UI 合同检查拒绝普通 `Button` 直接按异步状态切换文案；现有异步文字按钮迁移到同一组件。通知设置保存不再以缓存内容作为 React `key` 重新挂载整张表单，因此保存前后保持同一按钮与表单实例。接口、权限、保存 payload 与业务反馈不变。
- 原因：按钮文字长度变化和保存成功后的整块重挂载会造成操作区横向跳动、焦点丢失与“页面被替换”的观感。把两个状态预先纳入同一几何测量，并由可执行门禁约束后续代码，才能稳定所有类似操作而不依赖逐页面手工指定宽度。

### D203 Agent Workspace 复用普通 Gateway 并隔离临时管理连接

- 决策日期：2026-09-04
- 当前状态：本地实现与定向测试完成；未合并、未推送、未部署。
- 决策内容：新增 `/agent` 及 Tasks、Artifacts、Skills、Automations 子路由，完整对话与 Feed 紧凑 Agent rail 复用 Shell 常驻的同一普通 OpenClaw Hook、WebSocket、Session、Run、transcript 和草稿。普通 Session/Worktree/Task/Artifact/Skill 状态 RPC 只能通过 `hello.features.methods` 逐方法启用并严格投影；项目与 base ref 必须来自 Gateway 注册数据，子会话归属只信任 `parentSessionKey`。不新增 Inscope Agent 服务、数据库、Runner、Artifact Store 或 Gateway 代理。
- 管理边界：Skills 上传/安装/启停和 Cron 管理不升级普通凭据，而是创建内存-only 的独立临时设备与 WebSocket，请求且只请求 `operator.admin`，暴露固定 Skill/Cron allowlist，不接收聊天事件、不持久化、不自动重连，并在页面离开、显式关闭、失败或十分钟空闲后销毁。高级写操作只面向用户确认的独立 Gateway/信任域；共享 Gateway 保持普通聊天。Skill 固定 ZIP、SHA-256、512 KiB 顺序块与 commit-before-install；Automation 固定 `agentTurn`、isolated、无投递、新建默认停用。
- UI 与安全：HeroUI Pro 只提供视觉层级参考，代码仍使用现有 HeroUI v3 OSS 与 design-system。Agent Workspace 拥有独立三栏/Drawer/Sheet 响应式合同；Artifact 只按明确 provenance 查询，预览和下载受 MIME、2 MiB/50 MiB、同源与过期校验约束。原始思维、工具参数/结果、Token、私钥、文件块、Artifact 和临时 URL 不进入 Service、日志、遥测、transcript 或持久缓存。
- 原因：工作台必须让页面关闭后仍可由用户 Gateway 执行 Worktree 与 Automation，同时不能把宿主机权限或高权限凭据扩展到 Inscope 服务或普通聊天连接。用 capability-gated 浏览器直连和短时 admin 隔离，可以保留既有对话连续性并让每类副作用拥有清晰确认与失败边界。

### D204 OpenClaw 提升为与 Inscope 平级的产品工作区

- 决策日期：2026-09-04
- 当前状态：本地实现与定向测试完成；未合并、未推送、未部署。
- 决策内容：Agent 不再占用 Inscope 普通导航行，而由左上角产品切换器在 `Inscope — 订阅、阅读与追踪` 与 `OpenClaw — 对话、执行与自动化` 之间切换。切换器只按用户保存两个 allowlist 内的最近路由；普通 Gateway Runtime 继续由认证 Shell 持有，因此切换只能执行 SPA 导航，不能重建 Socket、创建 Session、发送消息、清空草稿或停止运行。
- 布局内容：OpenClaw 使用单层工作区，1024 px 起固定 288 px 会话侧栏，1440 px 起只在明确请求时停靠 360 px Context/Tasks/Artifacts 检查器；不再持久化或拖拽工作区栏宽。Tasks/Artifacts 深链保留对话挂载，Skills/Automations 使用完整中心页。小屏使用 Drawer/底部 Sheet，对话与 Composer 分别限制在约 860/920 px；信息流的紧凑 Agent 变体保持独立且不改视觉行为。
- 授权内容：临时 `operator.admin` 从首屏常驻大卡片改为写意图触发的 Modal/Sheet。授权成功只解锁动作，不自动执行原写操作；页面只显示小型授权状态和立即销毁入口，D203 的内存隔离、十分钟销毁、固定 allowlist 与共享 Gateway 禁止边界保持不变。
- 原因：旧的全局侧栏、五标签、会话栏和常驻上下文栏形成多重导航与连续卡片，压缩了真正的对话区，也错误地把执行环境表现成信息流的一个功能页。工作区切换和按需检查器能建立清楚的产品层级，同时保留运行时连续性和 Inscope 视觉语言。

### D205 Agent Workspace 以连接 epoch、可信根树和严格回执收敛

- 决策日期：2026-09-05
- 当前状态：本地实现、协议/组件测试和受控 Gateway 浏览器验收完成；未合并、未推送、未部署。
